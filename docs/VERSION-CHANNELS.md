# 在线版本选择

正式版与测试版使用相同的 jsDelivr 版本接口，不再加载可变分支地址。

- 正式通道只选择 `1.2.3` 或 `v1.2.3` 格式的最大版本。
- 测试通道只选择 `1.2.3-dev.4` 或带 v 前缀的最大版本，不退回正式版。
- 从 `data.jsdelivr.com/v1/package/gh/huayueshan/shujuku-scope-binding` 查询版本，再从 `cdn.jsdelivr.net` 加载该固定版本的清单和代码。
- 不请求 GitHub 网页或 GitHub API。若 jsDelivr 不可用，明确提示加载失败，可改用离线版。
- 成功的版本查询在本地缓存十分钟。重新加载不会延长缓存；过期后重新查询，没有后台轮询。
- 本地缓存使用 localStorage，按通道分开，只保存版本号和查询时间，不含聊天或绑定数据。浏览器禁止本地存储时，每次重新查询。
- jsDelivr 上游可能仍缓存版本列表；十分钟是客户端查询缓存期限，不是发布后必定可见的时限。
- 清单与代码的 SHA-256 必须一致才执行。哈希用于校验文件一致性，不是来源签名。

旧版静态 import 加载器需要更换一次正文，保留脚本 ID、data、启停和按钮配置。仅更新远端代码无法改变已安装加载器的逻辑。

发布测试版本时创建新的固定测试标签，不覆盖已发布标签，不再推进可变 dev 地址。正式 main、正式标签和旧版本文件不随测试更新。

安装 JSON 仅由作者在社区分发，不加入仓库或 Release 附件。
